How-to-Hexo-1

介绍从基础依赖安装到主题接入，使用 Hexo 搭建个人博客的入门流程。

发布
2025 · 10 · 24
篇幅
952 字 · 约 3 分钟

【Blog|Hexo】（一）如何利用Hexo框架构建你的首个个人网站？ ​

本篇概要：下载依赖、安装hexo、初步配置主题

“一些用过就忘，再用再查的事情，应该留下记录。”

0.为什么写这篇 ​

Hexo 这套东西其实不算难，但第一次配的时候，还是很容易在各种细节里来回查资料。

我写这篇的目的也很简单：把自己从 0 开始搭博客时踩过的流程顺一遍。这样以后自己回头看更方便，也希望能顺手帮到同样刚入门的人。

对 萌新 来说，Hexo 的好处挺明显：

  • 文档多，资料好找
  • 生态成熟，主题和插件很多
  • 配合 GitHub Pages 之类的静态托管，整体成本不高

1.先准备基础依赖 ​

Git：https://git-scm.com/

Node.js：https://nodejs.org/en/

这两个建议先装好，再往后继续。

2.Git Bash 启动与换源 ​

如果执行过程中遇到权限问题，可以尝试使用管理员身份运行。

先把 npm 切到国内镜像，下载速度会友好很多。

2.1 切换淘宝源 ​

bash
npm config set registry http://registry.npm.taobao.org/
1

2.2 查看当前源 ​

bash
npm get registry
1

2.3 切回官方镜像 ​

bash
npm config set registry http://www.npmjs.org
1

3.安装Hexo ​

bash
npm install -g hexo
1

检测安装成功？

bash
hexo v
1

若出现多行版本号，则安装成功

4.创建项目文件夹&初始化 ​

进入你准备放博客的文件夹，右键呼出 PowerShell，然后执行：

bash
hexo init
1

5.主题的安装 ​

这里以我现在在用的 Butterfly 主题为例。
当然，你也可以直接去 GitHub 搜 Hexo theme，可选项其实很多。

在 Hexo 根目录里安装 Butterfly：

5.1 安装主题 ​

powershell
git clone -b master https://github.com/jerryc127/hexo-theme-butterfly.git themes/butterfly
1

后续如果只是更新主题，可以在主题目录下执行 git pull

6.应用主题&安装依赖插件 ​

先修改 Hexo 根目录下的 _config.yml：

yaml
theme: butterfly
1

然后安装依赖：

powershell
npm install hexo-renderer-pug hexo-renderer-stylus --save
1

7.关于配置文件的一点个人建议 ​

我自己的做法是，在 Hexo 根目录创建一个 _config.butterfly.yml，然后把 node_modules\hexo-theme-butterfly 里的默认配置复制出来，单独放进去改。

这样会更清楚一些：

  • _config.yml 放全局配置，比如站点名、部署信息、URL
  • _config.butterfly.yml 专门放主题相关配置

后面你要改样式、导航、首页、侧边栏的时候，基本都会在主题配置里动。

收尾 ​

到这里，Hexo 和 Butterfly 的基础环境就差不多起来了。
